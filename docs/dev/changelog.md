# Changelog

One-line entry per merged PR. Newest first. Format:

```
- YYYY-MM-DD <type>(<scope>): <summary> (#<PR>)
```

Types match the commit convention in [`contrib.md`](./contrib.md): `feat`,
`fix`, `refactor`, `docs`, `test`, `chore`.
